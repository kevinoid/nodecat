Concatenate named files.
Parameters:
Name Type Attributes Description
fileNames Array.<string> Names of files to be concatenated, in the order in which their content will appear. Files may appear multiple times. If the Array is empty, no output will be written.

 Options.

<nullable>
 Callback with the first Error which occurred, if any. Note that concatenation continues after errors. Required if global.Promise is not defined.
